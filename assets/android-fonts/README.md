# Bundled fonts

Unmodified upstream files; SHA-256 hashes are recorded in SHA256SUMS.

- Noto Sans Symbols 2: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSansSymbols2 — SIL OFL 1.1, see NotoSansSymbols2-OFL.txt.
- Symbols Nerd Font Mono v3.4.0: https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/NerdFontsSymbolsOnly — see NerdFontsSymbols-LICENSE.txt.
- Android Noto Color Emoji: https://github.com/googlefonts/noto-emoji/blob/main/2D/fonts/NotoColorEmoji.ttf — SIL OFL 1.1, see ../android-fonts/NotoColorEmoji-OFL.txt.

Symbol fonts extend proportional/monospace fallbacks. Lucide keeps its own family. Android renders emoji clusters from the packaged color font, then uses native fallback shaping for missing scripts. The native keyboard remains the user's chosen Android IME.
