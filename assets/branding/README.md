# D4C branding

Selected logo: `d4c-logo-concept-3.png`, approved on 2026-11-18.
Generated with the built-in image generation tool as a logo-brand concept: interwoven white/pink dimensional doorways forming a D, cyan inner plane, two short upright fins, dark charcoal background, no lettering.

The source preview is preserved. Resized copies in `assets/icons` supply the native Linux window and launcher. Android launcher copies live in `android/res/mipmap-*`; the APK packager includes those resources.

Linux identity: `site.blig.D4C`, matching the desktop filename, icon name, and window application ID. After building, run `python3 scripts/install-desktop.py` inside the target desktop session. An explicit built binary path may be supplied as the first argument. The installer updates only D4C's per-user binary, entry, and icons.
